# Bynálix

本地優先的個人健康分析平台。
Bynálix 的設計目標是長期自我觀察，而非參與度優化。
追蹤、觀察並分析自己的長期行為數據 — 不依賴不透明的雲端服務或黑箱 AI 系統。

---
## 哲學

Bynálix 並不是為了提供答案告訴使用者如何生活，而是讓使用者自己看見答案。

它幫助使用者：
- 記錄長期個人數據
- 觀察行為模式
- 探索相關性
- 了解哪些因素真正影響自己

目標不是盲目優化，
而是透過自有數據進行更深入的自我理解。

---
## 功能

- 本地優先架構
- SQLite 結構化資料存儲
- 營養追蹤（食物、餐點、可重複使用的餐點範本）
- 運動追蹤 — 重量訓練（組數與次數）與間歇式有氧
- 身體組成追蹤（體脂、分部位肌肉量、體水分、內臟脂肪、腰圍）
- 目標與模式系統（體重、熱量、三大營養素與飲水目標）
- 睡眠與水分追蹤
- 歷史視覺化
- 相關性分析
- 自訂運動與食物
- App 鎖定 — PIN 與生物辨識解鎖（Android）
- 加密 CSV 匯出（密碼保護，AES-256）
- 完整資料庫匯出 / 匯入，用於備份與還原
- 離線優先
- 雙語支援（英文 / 中文）

## 更新紀錄

### v1.2.1
- **Bug 修正** — TDEE 活動乘數修正為 Harris-Benedict 標準（1.2–1.9×）；原本低估約 10–50%
- **營養素** — 模式設定新增脂肪熱量比例 slider（佔 TDEE 的 25–35%，預設 30%）；公式改為脂肪 = TDEE × 比例，碳水補足剩餘熱量
- **增肌速率** — 調整為保守數值：緩慢 0.10%、標準 0.15%、積極 0.25% 體重/週
- **體脂** — 個人頁面的體脂欄位初始化後鎖定，後續需透過體態測量或體重紀錄更新
- **體脂過期提醒** — 每個門檻只通知一次（30 / 45 / 75 / 105 / 135 / 165 / 180 天），體重列於 30–179 天顯示 ⚠️，180 天以上顯示紅色半透明
- **睡眠** — 新增起床時間欄位，自動回推入睡時間（起床時間 − 睡眠時長）
- **程式品質** — Statistics 頁面的空 catch 區塊改為 logError

### v1.2.0
- **程式架構** — 大規模內部重構：建立元件庫（EmptyState、StickyHeader、PillButton、CardHeader、Modal/Dialog/BottomSheet）、設計 token 系統（間距、字型），以及樣式集中管理
- **Bug 修正** — 有氧歷史紀錄現在可正確納入飛輪項目
- **CI/CD** — 透過 GitHub Actions 建立全平台自動化發布流程（Windows / macOS / iOS / Android）

### v1.1.0
- **趨勢分析頁** — Z-score 標準化趨勢折線圖（體重 / 睡眠 / 熱量），自適應斜率偵測與方向指示
- **延遲分析** — 三組 Lag 分析，分別對應體重、睡眠、熱量的變化
- **可靠性優化** — 改用 Robust Z-score（中位數 + MAD），最低有效資料門檻降為 7 天
- **基礎統計** — 新增相關係數排行 BarChart（比照進階頁）
- **歷史圖表** — 有氧時長與熱量消耗改用雙 Y 軸
- **Bug 修正** — 身體歷史 Drawer 背景透明問題修復

## Bynálix 為何存在

Bynálix 的誕生是為了幫助使用者使用自己的長期數據驗證想法，
而不是完全依賴一般化的網路建議。

---
## 相關性分析

相關性並不代表因果關係。
Bynálix 提供探索式分析，旨在幫助使用者觀察可能的長期行為模式。

---
## 隱私與資料所有權

- 不需要雲端帳號
- 不收集使用者資料
- 不顯示廣告
- 你的資料屬於你自己
- 可選的 App 鎖定（PIN / 生物辨識）
- 支援 SQLite 資料庫匯出
- 支援本地備份與還原

## 技術架構

- **前端**：React 18 + TypeScript + Tailwind CSS + Vite
- **後端**：Tauri v2（Rust）
- **資料庫**：SQLite（`@tauri-apps/plugin-sql`）
- **平台偵測**：`src/lib/platform.ts`
- **國際化**：`src/lib/i18n.ts`

## 路線圖

Bynálix 的發展重點將持續圍繞「本地優先與長期自我觀察」。

短期：
- UI 與效能優化
- 核心資料流與穩定性提升

中期：
- 擴充分析能力（趨勢、相關性、自動計算因子之間的有向關係網絡）
- 強化視覺化與互動體驗

長期：
- 更完整的個人資料匯出與遷移能力
- 多語言與跨平台體驗優化
- 資料庫靜態加密（SQLCipher，金鑰由 PIN / 生物辨識衍生）
