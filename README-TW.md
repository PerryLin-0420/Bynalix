# Bynálix

本地優先的個人健康分析平台。
Bynálix 的設計目標是長期自我觀察，而非參與度優化。
追蹤、觀察並分析自己的長期行為數據 — 不依賴不透明的雲端服務或黑箱 AI 系統。

---
## 哲學

Bynálix 並不是為了提供答案告訴使用者如何生活，而是讓使用者自己看見答案。

它幫助使用者：
- 記錄長期個人數據
- 觀察行為模式
- 探索相關性
- 了解哪些因素真正影響自己

目標不是盲目優化，
而是透過自有數據進行更深入的自我理解。

---
## 功能

- 本地優先架構
- SQLite 結構化資料存儲
- 營養追蹤（食物、餐點、可重複使用的餐點範本）
- 運動追蹤 — 重量訓練（組數與次數）與間歇式有氧
- 身體組成追蹤（體脂、分部位肌肉量、體水分、內臟脂肪、腰圍）
- 目標與模式系統（體重、熱量、三大營養素與飲水目標）
- 睡眠與水分追蹤
- 歷史視覺化，可選擇疊加趨勢擬合線
- 相關性分析 — 變因關係網絡，含延遲影響方向
- 規律發現 — 週末 vs 平日效應，經顯著性檢定過濾
- 時間線 — 讓分析區間逐日縮短，找出哪些因子長期都會影響你的目標、哪些是最近才開始出現影響
- 依螢幕活動自動偵測睡眠（Android）
- 自訂運動與食物
- App 鎖定 — PIN 與生物辨識解鎖（Android）
- 加密 CSV 匯出（密碼保護，AES-256）
- 完整資料庫匯出 / 匯入，用於備份與還原
- 離線優先
- 雙語支援（英文 / 中文）

## Bynálix 為何存在

Bynálix 的誕生是為了幫助使用者使用自己的長期數據驗證想法，
而不是完全依賴一般化的網路建議。

---
## 相關性分析

相關性並不代表因果關係。
Bynálix 提供探索式分析，旨在幫助使用者觀察可能的長期行為模式。

---
## 隱私與資料所有權

- 不需要雲端帳號
- 不收集使用者資料
- 不顯示廣告
- 你的資料屬於你自己
- 可選的 App 鎖定（PIN / 生物辨識）
- 支援 SQLite 資料庫匯出
- 支援本地備份與還原

## 技術架構

- **前端**：React 18 + TypeScript + Tailwind CSS + Vite
- **後端**：Tauri v2（Rust）
- **資料庫**：SQLite（`@tauri-apps/plugin-sql`）
- **平台偵測**：`src/lib/platform.ts`
- **國際化**：`src/lib/i18n.ts`

## 路線圖

Bynálix 的發展重點將持續圍繞「本地優先與長期自我觀察」。

短期：
- UI 與效能優化
- 核心資料流與穩定性提升

中期：
- 強化視覺化與互動體驗

長期：
- 更完整的個人資料匯出與遷移能力
- 多語言與跨平台體驗優化
- 資料庫靜態加密（SQLCipher，金鑰由 PIN / 生物辨識衍生）
